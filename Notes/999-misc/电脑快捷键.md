
Linux桌面快捷键分配原则：

1. `Super`（修饰键）→ 系统保留区
2. `Alt + 特殊按键` → 窗口管理，没有占据`Alt + 字母`
3. `Ctrl+Alt` → 第二优先级
4. `Ctrl` → 应用级（系统尽量不占）

- `Super` 是 GNOME 的"神圣空间"，大部分系统快捷键用它
- `Ctrl` 留给应用自己用（Ctrl+C/V 等），系统尽量不动


## 桌面级

### `Super`: WM和Shell

`Super + Tab`: 切换应用
`Super + D`: 显示桌面
`Super + h`: **最小化窗口**
`Super + 数字`：打开Dock上对应的应用。打开后想最小化要按`Super + h`
`Super +l`: 锁屏
`Super +箭头及HOME/END`: **窗口占左/右半屏，最大化，最小化**
`Super + Space`: 切换输入法

### `Alt + 特殊按键`: 窗口管理

Alt类快捷键一般系统不占用`Alt + 字母`, 只占用`Alt + 特殊按键`。

`Alt+空格`：**第一个选项是当前窗口截图并保存，非常有用**
`Alt+Tab`: 切换窗口
`Alt+Esc`: 轮转窗口
`Alt+F4`: 关闭窗口

### `Ctrl + Alt + 特殊按键`: 工作区管理


`Ctrl+Alt+↑`：	切换到上方工作区
`Ctrl+Shift+Alt+↑`:	移动窗口到上方工作区
`Ctrl+Alt+T`:	打开终端
`Ctrl+Alt+Delete`:	注销
`Ctrl+Alt+D`:	显示桌面， `Super + D`也是这个功能
`Ctrl+Alt+F1~F12`:	切换到虚拟终端（tty）
`Ctrl+Shift+Alt+R`: **打开录屏 UI**

## 应用级
### kitty

`Ctrl + Shift + T`: new tab
`Ctrl + Shift + o`: open window below(same dir)
`Ctrl + Shift + p`: open new tab(same dir)
`C+S+—`： font size -- 
`C+S++`： font size ++

### neovim

设置原则：
1. 需要快速打开的，又不容易产生严重后果的，采用少按键的。
2. 打开后会做很多操作的，或是误触产生严重后果的，采用多按键的。

规则：
全局用Meta和Meta+Shift控制。

| --- | ------ | --------------------------- | --- |
| M-p | neovim | 工程面板：NerdTree               |     |
| M-P | neovim | 查找Project：Telescope project |     |
| M-l | neovim | 符号列表：Tagbar                 |     |
| M-L | neovim | 搜索符号：Fzflua btags           |     |
| M-f | neovim | 搜索文件：Telescope find_files   |     |
| M-F | neovim | 搜索字符串：Telescope live_grep   |     |
| M-b | neovim | 搜索bufers                    |     |
| M-h | neovim | 搜索help_tags                 |     |
| M-g | neovim | 搜索git_files                 |     |
| M-t | neovim | 打开终端面板: repl                |     |
